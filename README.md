# Баскетбольный центр

Приложение про баскетбол: три лиги в одном месте — NBA, Евролига и Единая лига ВТБ.
Турнирные таблицы, сетки плей-офф, результаты и календарь, составы команд,
карточки игроков со статистикой, подробная статистика матчей и новости.

Задумано как мини-приложение внутри Telegram; пока работает как обычный сайт.

## Как запустить

Нужен Python 3.11 или новее.

```powershell
# виртуальное окружение
python -m venv .venv
.venv\Scripts\activate

# зависимости
pip install -r requirements.txt

# настройки (пока можно оставить пустыми)
Copy-Item .env.example .env

# запуск
uvicorn app.main:app --reload
```

Приложение откроется на `http://127.0.0.1:8000`.

Первый запуск долгий — несколько минут. Приложение скачивает команды, составы
и все матчи сезона по трём лигам. Дальше данные лежат в файле `basketball.db`
и обновляются в фоне, поэтому старт становится быстрым.

## Из чего состоит

```
app/
  main.py              веб-сервер и адреса запросов
  db.py                база данных (SQLite): таблицы и запросы
  season.py            определение текущего сезона каждой лиги
  stages.py            стадии турнира: регулярка, плей-ин, плей-офф
  brackets.py          сборка сетки плей-офф из матчей
  news.py              новости: чтение лент, фильтры, отсев повторов
  scheduler.py         фоновое обновление данных по расписанию
  config.py            настройки из переменных окружения
  adapters/
    nba.py             источник данных NBA
    euroleague.py      источник данных Евролиги
    vtb.py             источник данных Единой лиги ВТБ
static/
  index.html
  style.css
  js/app.js            весь интерфейс
```

Ключевая идея устройства: каждая лига живёт в своём адаптере и приводит данные
к одному общему виду. Всё остальное приложение про лиги ничего не знает — оно
работает с матчами, командами и игроками вообще. Чтобы добавить четвёртую лигу,
достаточно написать ещё один адаптер и вписать его в реестр `ADAPTERS` в
`main.py`.

Идентификаторы сущностей выглядят как `лига:код` — например, `nba:401811020`
или `euroleague:MAD`. По префиксу приложение понимает, какому адаптеру
адресовать запрос.

## Обновление сезона

Две лиги переходят на новый сезон сами:

- **Евролига** — по списку сезонов из источника. Причём участники и составы
  подхватываются раньше матчей: клубы объявляют заявки летом, а календарь
  выходит позже.
- **NBA** — по данным ESPN, там границы сезона приходят вместе с матчами.

**Единую лигу ВТБ нужно обновлять вручную раз в год.** У источника нет
справочника турниров, а их номера выданы произвольно и не вычисляются.
Когда лига объявит календарь нового сезона (обычно в конце августа):

1. Запусти `python explore_photos_and_vtb.py` — он переберёт номера
   и покажет найденные турниры Единой лиги.
2. Впиши найденные номера в начало `app/season.py`:
   - `VTB_SEASON_ID` — турнир, где матчей больше всего (весь сезон целиком),
   - `VTB_COMP_ID` — регулярный чемпионат,
   - `VTB_LABEL` — подпись вида `2026/27`.

Пока сезон не обновлён, приложение пишет об этом в лог при каждом запуске.

## Вспомогательные скрипты

Лежат в корне, запускаются отдельно и ничего в приложении не меняют —
только опрашивают источники и печатают, что нашлось.

- `explore_sources.py` — поля матчей, стадии турнира
- `explore_feeds.py` — проверка новостных лент
- `explore_seasons.py`, `explore_seasons2.py` — сезоны и составы
- `explore_photos_and_vtb.py` — фотографии игроков и поиск турниров ВТБ

## Настройки

Секреты хранятся в файле `.env`, который в репозиторий не попадает.
Список нужных переменных — в `.env.example`.

## Откуда берутся данные

- NBA — открытые адреса ESPN
- Евролига — `api-live.euroleague.net`
- Единая лига ВТБ — виджеты InfoBasket
- Новости — RSS: Yahoo Sports и CBS Sports (NBA), Eurohoops (Евролига),
  «Чемпионат» (ВТБ)

Новости показываются так, как их отдала лента: заголовок, аннотация, название
источника и ссылка на оригинал. Полные тексты статей приложение к себе
не копирует — этого требуют условия использования лент.
